# Chipped — Transform Basic Blocks Into Detailed Decorations

Chipped 9minecraft Mod turns basic building materials into thousands of new decorative blocks. The mod gives builders a massive palette of unique designs without needing to gather any new resources. You can quickly craft carved stone, patterned wool, and detailed wooden planks to make your houses look amazing.

Thousands of Variants: Adds dozens of carved, patterned, and textured designs for almost every common block in the game.

## What this build is

An unofficial rebuild of **Terraformers**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.

## Source code

Upstream terms are **ARR**, so the port tree is not published here. This repository is documentation. Questions about the build go to **9minecraft.net@gmail.com**.
